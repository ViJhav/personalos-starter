# Prompts

Saved routines. Each file is a set of instructions for Claude to follow.

Run one by typing `/prompt <name>`, for example `/prompt weekly-review` or `/prompt inbox-triage`. Claude matches the name loosely, so `/prompt weekly` works too. Typing `/prompt` on its own lists what is here.

Four ship with the vault:

- **`weekly-review.md`** — the one ritual that matters. Fifteen to twenty minutes, once a week.
- **`inbox-triage.md`** — empty the inbox into real homes. Run it whenever the inbox gets full.
- **`setup.md`** — the first-time interview. Safe to rerun: it only asks about what is still missing.
- **`area-interview.md`** — the deep pass that fills each area README from a question file you answer at your own pace.

## Adding your own

Write a markdown file describing what you want done, in enough detail that it works without you supervising it. Useful ones tend to be things you do repeatedly and slightly differently each time, which is exactly where a written procedure beats improvising.

Ideas that work well: prepping for a recurring appointment, planning a trip, a monthly money check-in, debriefing something that just finished, comparing options for a purchase.

Start each file with what it reads and what it is allowed to write, so it is obvious at a glance what running it will do.

**Let them evolve.** The most useful thing about these files is that every time a run goes slightly wrong, you can fix the instructions so it does not go wrong again. A prompt that has been corrected ten times is worth far more than one that was written perfectly once. Do not treat them as finished.
