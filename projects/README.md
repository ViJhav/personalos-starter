# Projects

Time-bound efforts that have a "done": a trip, a course, a move, a renovation, a job search, a claim, a side project.

One folder each, named `YYYY-MM-<short-name>` using the month it started (`2026-09-japan-trip`). The date prefix keeps them sorted and makes it obvious at a glance what has been sitting around.

Every project folder should appear in `current-state.md` under Active projects with one word of state. That list is what stops a project quietly disappearing.

**The test:** a project finishes, an area does not. Renovating the kitchen is a project. Maintaining the house is an area.

When a project is done, say so in its README, capture anything durable (a lesson, a decision, a vendor you would use again) into the relevant area file, and remove it from `current-state.md`. Keep the folder.

---

## Template for `projects/<name>/README.md`

The bar for this file: **it should be understandable cold, months later, with zero memory of the conversation that created it.** That is the whole reason projects have READMEs. If you can read it after eight weeks away and know what to do next, it is working.

Delete any section you do not need.

```markdown
# <Project>

## Purpose
Why this exists. One or two sentences.

## Current status
Where things actually stand right now. Keep this current, it is the
section you will read first when you come back to this cold.

## Desired outcome
What "done" looks like, concretely enough that you will know when you
get there.

## Constraints
Time, money, energy, other people, dependencies.

## Key decisions
Calls already made, so they do not get re-opened. Include the reasoning.

## Next actions
The next few concrete steps. Concrete means you could start one without
thinking. "Research flights" is not concrete. "Check Google Flights for
SFO-NRT the week of the 12th" is.
- [ ]

## Open questions
Things genuinely unresolved. Naming them stops them being a vague sense
of unease about the project.

## Reference
Links, confirmation numbers, contacts, related notes, documents.
```
